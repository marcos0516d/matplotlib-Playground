Axes3D - Graficos 3D

Crea graficos en tres dimensiones usando el modulo mplot3d.

from mpl_toolkits.mplot3d import Axes3D

fig = plt.figure(figsize=(10, 6))
ax = fig.add_subplot(111, projection='3d')

x = [1, 2, 3, 4, 5]
y = [5, 4, 3, 2, 1]
z = [1, 4, 9, 16, 25]

ax.plot(x, y, z, label='Curva 3D')
ax.set_xlabel('X')
ax.set_ylabel('Y')
ax.set_zlabel('Z')
ax.legend()

Scatter 3D

Visualiza puntos en 3 dimensiones con colores y tamanios variables.

Superficies 3D - plot_surface

Crea graficos de superficie para visualizar funciones de dos variables.

from mpl_toolkits.mplot3d import Axes3D

fig = plt.figure(figsize=(10, 8))
ax = fig.add_subplot(111, projection='3d')

x = np.linspace(-5, 5, 100)
y = np.linspace(-5, 5, 100)
X, Y = np.meshgrid(x, y)
Z = np.sin(np.sqrt(X**2 + Y**2))

ax.plot_surface(X, Y, Z, cmap='viridis', alpha=0.8)
ax.set_title('Superficie 3D')

FuncAnimation - Animaciones

Crea animaciones que actualizan frames para mostrar cambios dinamicos.

import matplotlib.animation as animation

fig, ax = plt.subplots()
line, = ax.plot([], [], 'r-')
x = np.linspace(0, 2*np.pi, 100)

def init():
    line.set_data([], [])
    return line,

def animate(i):
    y = np.sin(x + i * 0.1)
    line.set_data(x, y)
    return line,

ani = animation.FuncAnimation(fig, animate, init_func=init,
                              frames=100, interval=50)

Animaciones interactivas

Crea animaciones que responden a eventos del usuario.

# Usar blit para mejor rendimiento
ani = animation.FuncAnimation(
    fig, animate, init_func=init,
    frames=100, interval=50, blit=True
)

# Con frames infinitos
ani = animation.FuncAnimation(
    fig, animate, frames=None, interval=50
)

Guardar animaciones

Exporta animaciones a GIF o MP4.

# Guardar como GIF
ani.save('animacion.gif', writer='pillow', fps=30)

# Guardar como MP4
ani.save('animacion.mp4', writer='ffmpeg', fps=30)

# Con calidad personalizada
ani.save('animacion.mp4', writer='ffmpeg',
         fps=30, dpi=150, bitrate=2000)

savefig() - PNG de alta resolucion

Guarda graficos en PNG con DPI personalizado para impresion o web.

figure(figsize) - Tamanio y proporcion

Controla el tamanio y relacion de aspecto de tus figuras.

# Tamanio en pulgadas (ancho, alto)
fig = plt.figure(figsize=(12, 6))

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# Relacion de aspecto
ax.set_aspect('equal')  # Ejes iguales

Fuentes y texto personalizado

Personaliza fuentes, tamanios y estilos de texto en tus graficos.

# Configurar fuente globalmente
plt.rcParams['font.family'] = 'serif'
plt.rcParams['font.size'] = 12

# Fuente especifica en un elemento
plt.title('Titulo', fontsize=16, fontweight='bold', fontstyle='italic')
plt.xlabel('Eje X', fontfamily='monospace', fontsize=14)

# Con propiedades personalizadas
from matplotlib.font_manager import FontProperties
fp = FontProperties(family='sans-serif', size=12, weight='bold')
plt.text(0.5, 0.5, 'Texto personalizado', fontproperties=fp)

annotate() - Flechas y anotaciones

Agrega flechas y anotaciones personalizadas para resaltar puntos importantes.

# Anotacion simple
plt.annotate('Punto maximo', xy=(3, 9), xytext=(1, 7),
             arrowprops=dict(arrowstyle='->', color='red'),
             fontsize=12)

# Con caja de texto
plt.annotate('Importante', xy=(2, 4), xytext=(4, 6),
             arrowprops=dict(arrowstyle='->', facecolor='black'),
             bbox=dict(boxstyle='round,pad=0.3', facecolor='yellow'),
             fontsize=11)

twinx() - Ejes duplicados

Crea graficos con doble eje Y para comparar variables con diferentes escalas.

x = [1, 2, 3, 4, 5]
y1 = [10, 20, 30, 40, 50]  # Temperatura
y2 = [100, 200, 150, 300, 250]  # Ventas

fig, ax1 = plt.subplots()
ax1.plot(x, y1, 'b-', label='Temperatura')
ax1.set_ylabel('Temperatura (C)', color='b')

ax2 = ax1.twinx()
ax2.plot(x, y2, 'r-', label='Ventas')
ax2.set_ylabel('Ventas ($)', color='r')
